# Brain + Heart Skill Garden

An early browser prototype for a playful map of trainable human capacities.

## Volume Two

- Game cards now launch individual practice sessions.
- Completed sessions persist locally in the browser.
- Garden energy grows as practices accumulate.
- Connection pathways awaken as multiple capacities are practiced.
- The visual atlas has a lightweight 3D depth/orbit treatment.
- The reflection room is scaffolded for the next pass.

## Run locally

```bash
python3 -m http.server 4210
```

Then open <http://localhost:4210>.

## Product guardrails

The brain is a navigation metaphor for distributed capacities, not a claim that one isolated region owns one skill. HRV and body signals are optional trend signals, not diagnoses. Progress rewards practice and connection, not a medical score.
